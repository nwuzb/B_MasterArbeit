\section{Related Work}\label{section::relatedwork}

In recent years, passenger detection and counting methods based on deep learning have become an active research area. Researchers have explored various network architectures and techniques from different perspectives to address counting problems in public transportation and crowd scenarios.
\subsection{Traditional Crowd Counting Methods}
Before deep learning-based methods became mainstream, several traditional crowd counting methods existed. These methods typically relied on handcrafted features and classical machine learning algorithms.

In earlier studies, traditional approaches employed image-based local features for passenger detection and counting in buses, such as Histogram of Oriented Gradients (HOG) \cite{72_beforeway} and Hough transform \cite{73_Huofu}. However, these methods performed poorly in complex scenes and dynamic environments, primarily because manually designed features possess limited generalization capability, making it challenging to manage variations in appearance, occlusions, and changes in illumination.

\subsection{Density Estimation-based Methods}
Density estimation-based methods have demonstrated greater robustness in high-density crowd counting scenarios.
For instance, Anusiya et al. utilized Gaussian filters to create ground-truth density maps for crowd number estimation \cite{71_Density_estimation_method}. Moreno Rendon et al. proposed a computer vision-based approach employing deep learning techniques to estimate the number of passengers at TransMilenio bus stations. They introduced the TransMilenio-Javeriana dataset, containing nearly 900,000 head annotations from buses and stations, and trained a deep learning architecture specifically tailored for crowd counting tasks, generating density maps focused on head regions in various scenes \cite{41_moreno_rendon_passenger_2023}. Bai et al. presented a crowd density detection approach based on crowd aggregation patterns and multi-column convolutional neural networks, aiming to integrate real-time surveillance videos captured from multiple viewpoints and granularities \cite{06_bai_crowd_2021}.

\subsection{Crowd Counting Based on Object Detection}
Different from density map estimation methods, crowd counting methods based on object detection directly regard each individual in a crowd as a target to be detected. These methods generally employ existing object detection models (such as Faster R-CNN, SSD, YOLO, etc.) to locate people in images and obtain the total number of people by counting the detected targets. The progress of deep learning technology has significantly improved the accuracy of object detection in complex scenes, making crowd counting methods based on object detection an important research direction.

For example, Mukti et al. studied an automatic passenger counting (APC) technology based on face detection, which uses the Viola-Jones method for face detection. In addition, this method is integrated with an embedded system based on the Internet of Things for processing and data transmission \cite{43_mukti_pemodelan_2021}. The team of Islam also proposed a passenger seat availability framework based on face detection, which detects the face of each passenger in a bus and sends the data of empty and occupied seats to the data center \cite{24_islam_framework_2020}.

The Pronello team developed a low-cost APC system using a Raspberry Pi with a camera and the YOLOV5 object detection algorithm, and conducted a field experiment in cooperation with the cities of Turin and ASTI in Italy. The experiment shows that the low-cost system was able to achieve an accuracy of 72.27\% and 74.59\% \cite{49_pronello_evaluating_2023}.

Tsiktsiris et al. proposed an end-to-end, rotation-aware detection framework specifically designed for accurately detecting passengers using angle-oriented bounding boxes, especially for top-view fisheye images. It locates people in images and obtains the total number of people by counting the detected targets\cite{55_tsiktsiris_improving_2024}.


\subsection{Other Related Methods}
Zhang et al. proposed a passenger counting method for buses based on the Single Shot MultiBox Detector (SSD) and Kalman filtering. In their method, the SSD model was adapted into a binary classifier trained specifically on bus passenger datasets. This model detects passengers in each frame, while a Kalman filter tracks detected positions across consecutive frames. Ultimately, passenger boarding and alighting statistics are generated based on these trajectories \cite{66_zhang_bus_2020}. Ahmed introduced a novel technique that transforms regions of interest containing pedestrians into standardized shapes, then applies the Rotated Histogram of Oriented Gradients (RHOG) algorithm and an SVM classifier based on machine learning. This method significantly improves pedestrian detection performance across different overhead scenarios \cite{05_ahmed_person_2019}.

Apart from vision-based methods, other sensor technologies have also been explored for passenger counting applications. Haig et al. examined an approach that detects real-time bus occupancy using mobile phones. Their participatory sensing system utilizes various built-in smartphone sensors, such as accelerometers and global positioning systems (GPS), to indirectly infer bus occupancy and passenger numbers through sensor data analysis \cite{18_haig_real-time_2021}. The Shibata research team studied a crowd density estimation system using cellular communication radio-wave sensing combined with deep learning, specifically aiming to address privacy concerns \cite{52_shibata_people_2019}. Michele Nitti et al. investigated a method utilizing WiFi transmission to monitor mobile devices, enabling measurement of passenger load on buses \cite{70_noauthor_iabacus_nodate}.

Liu et al. proposed an automatic passenger boarding and alighting detection algorithm for subways based on deep learning and optical flow. The algorithm consists of a MetroNext network, which integrates two Multiple Scales Attention Convolution (MSAC) blocks, along with an optical flow algorithm. This combination rapidly and accurately detects subway cars and passengers, predicting passenger movement directions to determine boarding or alighting activities \cite{38_liu_automatic_2021}.

In summary, crowd counting methods are transitioning from hand-crafted features and regression models to end-to-end deep learning solutions \cite{13_dogra_survey_2024}. In high-density scenarios with severe inter-person occlusions, density-map-based approaches exhibit notable advantages \cite{17_gupta_crowd_2024}. For instance, in the extremely crowded MOT20 setting, CountingMOT leverages density maps to identify occluded or missed targets and to correct false detections, thereby substantially improving multi-object tracking (MOT) performance \cite{125}. Nevertheless, a recent survey by Gang et al. indicates that, while considerable progress has been made in analysis, counting, and classification, substantial research opportunities remain in crowd detection and crowd simulation \cite{01_noauthor_deep_2024}.


\begin{itemize}
  \item \textbf{Intelligent surveillance and safety}: In intelligent surveillance systems, crowd counting can be used to detect anomalous events, such as sudden short-term crowd aggregation or unusual flow dynamics, which is critical for public safety in high-density areas like railway platforms \cite{01_noauthor_deep_2024}. Such systems are essential for understanding dynamic crowd behaviors, enabling crowd management, and analyzing individual activities to ensure public safety and security, optimize public spaces, and support effective event management \cite{15_ganga_object_2024}. Typical functionalities include monitoring movement, speed, and flow direction, as well as detecting anomalous events such as fights or running \cite{03_abdou_crowd_2020}.
  \item \textbf{Transportation systems}: In public transportation, crowd counting is widely used to estimate the number of passengers (e.g., on buses) to optimize routes and schedules, improve convenience, reduce operational costs, and conserve energy \cite{33or34_li_lightweight_2023}. For example, crowded buses can be detected in real time to support dynamic dispatching strategies on congested routes \cite{55_tsiktsiris_improving_2024}. In metro platform scenarios, real-time passenger detection networks such as MPDNet (Transformer-based) have been proposed to promptly and accurately acquire passenger-flow data, thereby supporting operational decision-making and ensuring safe and efficient metro operations \cite{64_yang_mpdnet_2022}.
  \item \textbf{Public infrastructure planning}: Crowd counting data can be used to assess flow patterns in various public venues and to inform infrastructure design and expansion. By tracking inflow and outflow at shopping malls, transport hubs, and airports, the efficiency of entrance and exit configurations can be evaluated. Optimizing these configurations can improve flow efficiency, enhance safety, and minimize waiting times \cite{17_gupta_crowd_2024}.
  \item Taken together, accurate crowd counting provides precise information on population density, behavioral patterns, and transportation usage, thereby enabling urban planners, public transport operators, and infrastructure managers to make better-informed decisions that optimize existing infrastructure and guide future development.
\end{itemize}

\subsection{Overview of Multi-Object Tracking}
Multi-object tracking (MOT) is a fundamental and pivotal task in computer vision. The core objective is to simultaneously localize multiple objects of interest (e.g., pedestrians, vehicles, animals) in video sequences and to assign and maintain a unique identity (ID) for each object, thereby constructing complete trajectories over time \cite{103}\cite{116}\cite{152}. Unlike single-object tracking (SOT), MOT must handle target entries and exits, inter-object similarity, and complex interactions \cite{86}.

\subsubsection{Detector Components}

In MOT, the detector and the tracker play distinct yet interdependent roles, jointly determining overall system effectiveness.

\subsubsection{Detector}
Prior to discussing MOT algorithms, it is crucial to consider the detector, which is responsible for identifying and precisely localizing all objects of interest in each frame and for providing bounding boxes, classes, and confidence scores. Detector performance directly affects downstream tracking accuracy: any false negatives may cause target loss, whereas false positives may introduce spurious trajectories \cite{169}.

Common choices and functionality include:

\begin{itemize}
    \item \textbf{Two-stage detectors}: First generate region proposals and then perform classification and bounding-box regression. Faster R-CNN is representative of this class, known for high accuracy but relatively slower speed \cite{88}.
    \item \textbf{One-stage detectors}: Directly predict bounding boxes and classes from images without a proposal stage. These detectors typically offer significant speed advantages and are better suited to real-time applications \cite{145}.
    \item \textbf{YOLO family (You Only Look Once)}: As a prominent one-stage detector, the YOLO series (from YOLOv3 through YOLOv10 and up to YOLOv12) achieves an excellent balance between speed and accuracy. For example, YOLOv5 has been widely adopted for vehicle recognition \cite{121} and crowd detection \cite{105}. YOLOv8 further improves pedestrian detection accuracy and reduces model size via techniques such as Soft-NMS and GhostConv \cite{190}. YOLOv9 integrates optical flow to enhance tracking accuracy and robustness, particularly under occlusion, appearance variation, and fast motion \cite{141}. YOLOX is favored by leading trackers such as ByteTrack due to its efficiency and strong detection performance \cite{90}.
\end{itemize}

\subsubsection{Mainstream MOT Frameworks}

Contemporary MOT methods can be broadly categorized into two families: Tracking-by-Detection (TBD) and Joint Detection and Embedding (JDE). In recent years, with the advent of Transformer-based models and related techniques, several end-to-end approaches have also emerged.

\textbf{Tracking-by-Detection (TBD)}. The TBD paradigm is among the earliest and most widely adopted in MOT. It decomposes MOT into two sequential stages: object detection and data association. A pre-trained detector first identifies and localizes targets independently in each frame, after which an association algorithm matches detections to existing trajectories to maintain identity continuity \cite{152}.

Representative methods include: SORT (Simple Online and Realtime Tracking; Bewley et al., 2016), which pioneered the use of the Kalman filter for motion prediction and employed the Hungarian algorithm with IoU-based costs for data association, enabling simple and efficient real-time tracking \cite{169}. DeepSORT (Wojke et al., 2017) augments SORT with deep appearance embeddings (Re-ID features), combining motion (Kalman filtering) and appearance (cosine similarity) information and using a cascaded matching strategy to significantly reduce identity switches, thereby improving robustness and accuracy in complex scenarios \cite{211}. Advantages include a clear, modular design that permits independent optimization of the detector and tracker; a stronger detector often directly improves tracking performance. A limitation is that detection and tracking are decoupled, which may reduce efficiency and hinder truly end-to-end optimization; when targets are occluded or absent, reliance on detections alone can lead to trajectory fragmentation and ID switches \cite{175}.

\textbf{Joint Detection and Embedding (JDE)}. JDE aims to overcome TBD limitations by integrating object detection and Re-ID (appearance feature learning) into a unified network for joint training. The goal is to improve efficiency while boosting tracking performance through shared feature learning \cite{173}\cite{90}.

Representative methods include: FairMOT (Zhang et al., 2020), a CenterNet-based joint detection and tracking framework with two homogeneous branches for detection and Re-ID, which showed that center-based embeddings are more suitable for tracking than anchor-based ones \cite{208}. ByteTrack (Zhang et al., 2021) builds upon YOLOX as the detector and introduces a simple yet effective association strategy that makes effective use of low-confidence detections to handle occlusion and trajectory fragmentation, achieving state-of-the-art performance on MOTChallenge \cite{110}. While shared features improve computational efficiency and runtime—beneficial for real-time applications—and support end-to-end optimization, joint learning of detection and embedding may introduce conflicts that affect detection performance; in crowded scenes, anchor-based detectors may suffer from ambiguity when learning Re-ID features \cite{173}.

\textbf{Emerging methods (Transformer, attention, Siamese, GNN, etc.)}. With the evolution of deep architectures, emerging methods strive to more deeply integrate detection, tracking, and association for truly end-to-end tracking and reduced reliance on heuristic matching \cite{108}. Representative examples include Transformer-based MOTR (Zeng et al., 2021), which extends DETR with track queries to model tracked instances and performs end-to-end tracking via iterative updates across frames \cite{131}; TransTrack (Sun et al., 2020) \cite{97} and TrackFormer (Meinhardt et al., 2022) \cite{164}, which leverage the query–key mechanism of Transformers to decouple detection and association; attention-based VGT-MOT (Wang et al., 2023) \cite{85}, which predicts target positions using inter-frame attention and adaptively fuses motion and appearance similarity to handle occlusion; Siamese-based approaches such as SiamMOT (Wang et al., 2021) \cite{151}; and graph neural networks (GNNs) that model complex spatiotemporal relations among targets by treating detections or trajectories as nodes with edges encoding similarity or associations, such as GMTracker (He et al., 2021), which emphasizes inter-frame matching and intra-frame context \cite{209}. These methods promise more robust end-to-end training and inference under complex scenes and nonlinear motion, but often entail high model complexity, substantial compute, longer training time, and dependence on dataset scale—for example, smaller datasets like MOT17 may be insufficient to fully train query-based trackers \cite{155}.

\subsection{Challenges in Complex Scenarios}
Despite recent advances, MOT in high-density, complex, and real-time scenarios—\\linebreak particularly railway platforms—remains challenging \cite{59_wang_deep_2024}.
\textbf{Occlusion}. In crowded platform environments, pedestrians are densely packed and are frequently mutually occluded or blocked by fixed structures (e.g., pillars, billboards, train bodies). This hinders accurate bounding-box detection and stable appearance feature extraction, leading to missed detections and identity loss \cite{91}. TBD methods degrade significantly under such conditions; while DeepSORT mitigates these issues via appearance features and cascaded matching, it can still fail under prolonged or severe occlusion \cite{134}.
\textbf{Identity switches (IDS)}. When multiple targets exhibit similar appearance (e.g., uniforms) or reappear after complex motion, fast movement, or long-term occlusion, trackers may confuse identities or assign the same ID to different trajectories, causing ID switches \cite{87}. IDS is a key robustness indicator. DeepSORT substantially reduces IDS by incorporating appearance cues, yet it remains a major challenge in crowded scenes \cite{134}.
\textbf{Real-time–accuracy trade-off}. In settings requiring immediate response (e.g., platforms), MOT systems must operate in real time. Failure to update passenger-flow information promptly undermines early warning and scheduling. However, improving accuracy often entails more complex models and higher computational cost, which conflicts with real-time requirements \cite{203}. YOLO detectors are renowned for balancing speed and accuracy, making them common choices for real-time MOT, though trade-offs persist at high frame rates.
\textbf{High-density crowds and complex backgrounds}. Platform scenes often feature high-density crowds and complex, dynamic backgrounds (e.g., trains arriving/departing, changing signage, luggage), complicating foreground–background separation and inter-object motion modeling \cite{86}. Density-map-based methods can be advantageous in such scenarios. For example, YOLOv8 (Xiao et al., 2023) trained on CrowdHuman targets high-density pedestrian detection, while YOLOv10 with NMS-free training and consistent dual assignment better recognizes overlapping targets.
\textbf{Small-object detection}. Distant individuals or those occupying few pixels are easily missed due to weak features \cite{28_kaur_comprehensive_2023}.
\textbf{Illumination variation}. Platform lighting conditions vary substantially (e.g., direct sunlight, low-light nighttime, transient shadows), degrading appearance stability and thereby detection and tracking performance \cite{169}.
\textbf{Generalization and annotation dependency}. Deep models rely on large-scale, high-quality annotations; MOT models are often trained on specific datasets, while real-world diversity (camera angles, resolutions, environments) demands strong generalization \cite{02_noauthor_review_nodate}.

\subsection{Proposed Approach: YOLOv11 + DeepSORT}
Given the above challenges—especially in railway platforms we propose combining YOLOv11 with DeepSORT based on an analysis of their respective strengths and complementary capabilities in handling real-world complexity.
\subsubsection{YOLOv11: Strong Detection Advantages}
Reviewing the evolution of the YOLO family (e.g., YOLOv5, YOLOv8, YOLOv9, YOLOv10, and YOLOv12), future versions are expected to further advance detection accuracy, speed, and model compactness. As a single-stage detector, YOLO excels at real-time tasks, outputting high-confidence bounding boxes that are critical inputs for downstream tracking. We anticipate YOLOv11 will offer the following advantages:
\begin{itemize}
    \item High-accuracy detection: Accurately identifies pedestrians on railway platforms, reducing missed and false detections.
    \item Real-time processing: Meets real-time requirements under high frame rates, matching the dynamics of our target scenarios.
    \item Small-object sensitivity: Further improves detection of distant or partially occluded small targets, particularly relevant to head detection.
    \item Robustness: Adapts to illumination changes and complex backgrounds, providing stable detection outputs in platform environments.
\end{itemize}

\subsubsection{DeepSORT: Robust Tracking}
DeepSORT is a well-regarded tracker within the TBD paradigm, noted for handling occlusion and markedly reducing ID switches. It combines Kalman filtering for motion prediction with deep appearance embeddings for identity association \cite{174}.
\begin{itemize}
    \item Occlusion handling: With deep Re-ID features, DeepSORT re-identifies targets after long occlusions, compensating for transient detector failures; in our work, we also train a Re-ID model on our custom dataset.
    \item Identity consistency: Appearance features strengthen discrimination among similar targets, substantially reducing IDS and ensuring continuous, accurate trajectories.
    \item Predictive capability: The Kalman filter leverages historical motion to predict positions in subsequent frames, maintaining trajectories during brief occlusions or at lower frame rates.
\end{itemize}

\subsubsection{Complementarity and Synergy}
The combination of YOLOv11 and DeepSORT capitalizes on their complementary strengths in MOT:
\begin{itemize}
    \item Strong detection plus strong tracking: YOLOv11 provides high-quality, efficient detections as a foundation, while DeepSORT's advanced association mechanisms handle challenges such as occlusion, maintaining trajectory continuity and identity consistency.
    \item Adaptation to platform scenes: In high-density, high-occlusion, and dynamically changing platform environments, YOLOv11 maximizes target recall, whereas DeepSORT's occlusion handling and ID management mitigate identity switches and trajectory fragmentation. This synergy improves tracking accuracy and robustness under real-time constraints for complex, application-specific scenarios.
\end{itemize}

Together, these components enable the construction of an efficient, accurate, and robust MOT system tailored to the demanding conditions of railway platforms.

\subsection{多目标跟踪任务简介}
多目标跟踪（Multi-Object Tracking, MOT） 是计算机视觉领域的一项基础且关键任务,其核心目标是在视频序列中同时定位多个感兴趣的目标（如行人、车辆、动物等），并为每个目标分配并维持一个唯一的身份标识（ID），从而构建它们在时间上的完整运动轨迹\cite{103}\cite{116}\cite{152}。与单目标跟踪（SOT）不同，MOT需要处理目标出现与消失、个体间的相似性以及复杂的交互行为\cite{86}。

MOT技术在广泛的实际应用场景中具有重要价值，包括但不限于：智能交通与自动驾驶（实时监测道路上的车辆和行人，提升行车安全和交通效率\cite{162}）；视频监控与公共安全（对人群进行计数、分析行为模式，预防和应对突发事件\cite{60_wang_catrack_2025}）；机器人导航与人机交互（使机器能够感知并跟踪周围环境中的动态实体\cite{160}）；体育赛事分析（对运动员的运动轨迹进行分析，辅助战术制定和表现评估\cite{200}）；野生动物管理（评估野生动物数量，促进生态保护\cite{91}）。

\subsubsection{检测器组成分析}

在MOT任务中，检测器和跟踪器扮演着不同的角色，但其性能相互影响，共同决定了整体跟踪系统的有效性。

\paragraph{检测器（Detector）}
在谈论多目标跟踪算法之前，一个重要的组成部分是检测器，检测器负责在每一帧图像中识别并精确定位所有感兴趣的目标，并提供它们的边界框、类别和置信度分数。检测器的性能直接影响到后续跟踪的准确性，因为任何漏检（False Negative）都可能导致目标丢失，而误检（False Positive）则可能引入虚假轨迹\cite{169}。

常见选择与功能包括：

\begin{itemize}
    \item 两阶段检测器：首先生成候选区域，然后对这些区域进行分类和边界框回归。Faster R-CNN是其代表，以高精度著称，但速度相对较慢\cite{88}。
    \item 单阶段检测器：直接从图像中预测目标的边界框和类别，无需区域提议步骤。它们通常在速度上具有显著优势，更适合实时应用\cite{145}。
    \item YOLO系列 (You Only Look Once)：作为单阶段检测器的杰出代表，YOLO系列算法（从YOLOv3到YOLOv10，乃至YOLOv12）在速度与精度之间取得了卓越的平衡。例如，YOLOv5因其快速、高精度的特性被广泛应用于车辆识别\cite{121}和人群检测\cite{105}。YOLOv8通过SoftNMS、GhostConv等技术进一步提升了行人检测精度并减小了模型尺寸\cite{190}。YOLOv9结合光学流进一步增强了跟踪精度和鲁棒性，尤其是在遮挡、外观变化和快速运动等复杂场景下\cite{141}。YOLOX因其高效率和强大检测性能被ByteTrack等领先跟踪器采用\cite{90}。
\end{itemize}


\subsubsection{MOT主流框架介绍}

当前，多目标跟踪算法主要分为两大类：基于检测的跟踪（Tracking-by-Detection, TBD）和联合检测与嵌入（Joint Detection and Embedding, JDE）。但近年来，随着Transformer等技术的兴起，也出现了一些新兴的端到端（End-to-End）方法。

基于检测的跟踪（Tracking-by-Detection, TBD）
TBD范式是MOT领域最早期且最广泛采用的方法。它将MOT任务分解为两个独立的顺序阶段：目标检测和数据关联。首先，使用一个预训练的检测器在每一帧中独立地识别并定位目标。然后，利用关联算法将这些检测框与现有轨迹进行匹配，以维持目标的身份连续性\cite{152}

代表性算法包括：SORT（Simple Online and Realtime Tracking, Bewley等人，2016）开创性地将卡尔曼滤波器用于运动预测，并通过匈牙利算法基于检测框的IoU（Intersection over Union）进行数据关联，实现了简单高效的实时跟踪\cite{169}；
DeepSORT（Wojke等人，2017）在SORT的基础上引入了深度外观特征嵌入（Re-ID特性），通过结合运动信息（卡尔曼滤波）和外观信息（余弦相似度）来建立关联，并通过级联匹配策略显著减少了身份切换（ID Switch）的发生，提升了跟踪的鲁棒性和准确性，使其在复杂场景中表现更优\cite{211}。该方法的优点在于结构清晰、模块化强，允许独立优化检测器和跟踪器，强大的检测器可以直接带来跟踪性能的提升；缺点是检测和跟踪是分离的，可能导致效率低下，难以实现真正的端到端优化，在目标遮挡或消失时，纯粹依赖检测结果可能导致轨迹碎片化和ID切换\cite{175}。

联合检测与嵌入（Joint Detection and Embedding, JDE）
JDE范式旨在克服TBD方法的局限性，将目标检测和Re-ID特征嵌入（或外观特征学习）整合到一个统一的网络框架中进行联合训练。这种方法的目标是在提高效率的同时，通过共享特征学习来提升跟踪性能\cite{173}\cite{90}。

代表性算法包括：FairMOT（Zhang等人，2020）是一个基于CenterNet的联合检测与跟踪框架，它通过两个同质分支分别执行目标检测和Re-ID特征提取任务，并且发现基于中心点的嵌入比基于锚框的嵌入更适合跟踪\cite{208}；
ByteTrack（Zhang等人，2021）通过利用YOLOX作为检测器，并引入一种简单而有效的关联策略，即使是低置信度的检测框也能被充分利用，从而有效处理遮挡和轨迹碎片化问题，在MOTChallenge数据集上取得了领先性能\cite{110}。该方法的优点在于通过共享网络提高计算效率和运行速度，更适合实时应用，能够进行端到端优化，提升整体性能；缺点是检测和嵌入任务的联合学习可能存在冲突，影响检测性能，尤其是在拥挤场景中，锚框式检测器在学习Re-ID特征时可能存在模糊性\cite{173}。

新兴方法（Transformer、注意力机制、Siamese、GNN等）
近年来，随着深度学习架构的不断演进，一些新兴方法致力于更深层次地融合检测、跟踪与关联任务，以实现真正的端到端跟踪，减少对传统启发式匹配的依赖\cite{108}。
代表性算法包括：基于Transformer的MOTR（Zeng等人，2021）扩展了DETR框架，引入"轨迹查询（track query）"来建模视频中被跟踪的实例，通过帧间迭代更新和预测实现端到端跟踪\cite{131}，
TransTrack（Sun等人，2020）\cite{97}和TrackFormer（Meinhardt等人，2022）\cite{164}也利用Transformer的查询-键（query-key）机制将MOT解耦为检测和关联子任务；
注意力机制如VGT-MOT（Wang等人，2023）\cite{85}利用帧间注意力机制预测目标位置，并自适应融合运动和外观相似性来处理遮挡问题；
Siamese网络通过学习目标对之间的相似性度量来进行跟踪，在高密度场景下表现出一定的优势，SiamMOT（Wang等人，2021）\cite{151}等方法结合Siamese网络进行运动建模和关联；
图神经网络（GNN）能够有效地建模目标之间复杂的空间-时间关系，将检测框或轨迹视为图节点，边表示它们之间的相似性或关联性，从而解决多目标关联问题，例如GMTracker（He等人，2021）强调帧间匹配和帧内上下文\cite{209}。
这些方法的优点在于有望实现更鲁棒的端到端训练和推理，在复杂场景和非线性运动模式下具有更大的潜力；缺点是模型复杂性高，通常需要巨大的计算资源和更长的训练时间，且对数据集规模存在一定的依赖，如MOT17等小型数据集可能不足以充分训练基于查询的跟踪器\cite{155}。


\subsection{当前在复杂场景中面临的挑战}

尽管MOT技术取得了显著进步，但在高密度、复杂背景、实时性要求高的真实世界场景（特别是铁路站台这类场景）中，仍面临诸多挑战\cite{59_wang_deep_2024}。

遮挡问题（Occlusion）:在铁路站台等拥挤环境中，行人高度聚集，个体之间经常发生相互遮挡或被场景中的固定设施（如立柱、广告牌、列车车体）遮挡。这导致检测器难以捕获完整的目标边界框或提取稳定的外观特征，进而引发漏检和身份丢失\cite{91}。

传统的TBD方法在此类场景中性能下降显著，而DeepSORT通过引入外观特征和级联匹配可在一定程度上缓解，但当遮挡时间过长或遮挡程度极端时，仍可能失效\cite{134}。

身份切换（Identity Switch, IDS）:当多个目标外观相似（例如穿着相似制服的员工或乘客），或者目标在复杂运动、快速移动、长时间遮挡后重新出现时，跟踪器容易将不同目标的ID混淆或将同一目标的ID分配给不同的轨迹，导致身份切换\cite{87}。IDS是衡量跟踪算法鲁棒性的关键指标之一。DeepSORT通过结合外观特征显著降低了IDS，但仍是拥挤场景下的主要挑战\cite{134}。

实时性与精度的权衡:在铁路站台等需要即时响应的场景中，MOT系统必须具备高实时性。例如，如果系统无法实时更新客流信息，就无法及时进行预警或调度。然而，提升精度往往意味着更复杂的模型和更高的计算开销，这与实时性要求相矛盾\cite{203}。YOLO系列检测器以其在速度和精度上的良好平衡而闻名，这使其成为实时MOT的常见选择。然而，在高帧率下仍需权衡。

高密度人群与复杂背景:站台场景通常表现为高密度人群，同时背景复杂且动态多变（如列车进出、指示牌灯光变化、乘客行李等）。这使得目标与背景难以区分，且目标个体之间的运动相互影响，导致运动模式难以学习\cite{86}。基于密度图的方法在此类场景中表现出显著优势。YOLOv8 (Xiao等人，2023) 在CrowdHuman数据集上进行训练，针对行人高密度场景进行了优化。YOLOv10通过无NMS训练和一致双分配策略，能够更好地识别重叠目标。

小目标检测:当摄像头距离较远或目标个体在画面中占比很小时，它们就成为小目标。小目标由于像素信息少，特征不明显，极易被漏检\cite{28_kaur_comprehensive_2023}。

光照变化:站台环境的光照条件可能复杂且动态变化，例如白天阳光直射、夜晚灯光昏暗、列车驶过时的阴影变化等。这些变化会显著影响目标外观特征的稳定性，导致检测器和跟踪器的性能下降\cite{169}。

模型泛化能力与标注依赖性:此外，深度学习方法对大规模高质量标注数据的依赖性强，而MOT模型通常在特定数据集上训练，实际场景的多样性（不同摄像头角度、分辨率、环境条件）要求模型具有良好的泛化能力\cite{02_noauthor_review_nodate}。

\subsection{本研究方案：YOLOv11 + DeepSORT}

鉴于上述在复杂场景，特别是铁路站台环境下多目标跟踪面临的严峻挑战，本研究提出采用YOLOv11与DeepSORT相结合的方案。这种选择是基于对现有算法优劣势的深入分析以及它们在处理实际场景复杂性方面的互补性。

\subsubsection{YOLOv11：强大的检测优势}

回顾YOLO系列的演进（例如YOLOv5, YOLOv8, YOLOv9, YOLOv10和YOLOv12），我们可以预见未来的YOLO版本将继续在检测精度、速度和模型轻量化方面取得突破。YOLO系列以其单阶段、快速、高精度的特点，尤其是在处理实时任务方面表现出色。它能有效输出高置信度的边界框，这对于作为后续跟踪模块输入的检测结果至关重要。我们预期YOLOv11将在以下方面提供优势：
\begin{itemize}
    \item 高精度检测：能够准确识别铁路站台场景中的行人，减少漏检和误检。
    \item 实时性处理能力：确保在处理高帧率视频流时满足实时性要求，针对我们快速移动的场景下。
    \item 对小目标的适应性：预期YOLOv11将进一步提升对远距离或部分遮挡小目标的检测能力，针对我们的检测目标为头部的情况下。
    \item 鲁棒性：能够适应光照变化和复杂背景，提供稳定的检测输出，针对我们站台的光照变化和背景。
\end{itemize}

\subsubsection{DeepSORT：强大的跟踪鲁棒性}
DeepSORT是TBD范式中公认的优秀跟踪器，以其在处理遮挡和显著减少ID切换方面的出色表现而备受青睐。其核心在于结合了卡尔曼滤波器进行运动预测和深度外观特征嵌入进行身份关联\cite{174}。
\begin{itemize}
    \item 遮挡处理：通过深度Re-ID特征，即使目标被长时间遮挡后重新出现，DeepSORT也能基于其外观信息进行重新识别，有效弥补检测模块可能存在的瞬时漏检，因此我们也利用我们自己构建的数据集进行了ReID模型的训练。
    \item 身份一致性：外观特征的使用大大增强了模型区分相似目标的能力，从而显著降低ID切换的频率，确保轨迹的连续性和准确性。
    \item 预测能力：卡尔曼滤波器能够根据历史运动状态预测目标在下一帧的位置，有助于在短暂遮挡或帧率较低时维持轨迹。
\end{itemize}

\subsubsection{互补性与协同效应}

本研究方案选择YOLOv11与DeepSORT的结合，正是看重了两者在MOT任务中的互补性：
\begin{itemize}
    \item 强检测与强跟踪的结合：YOLOv11提供高质量、高效率的检测结果，为DeepSORT奠定坚实基础。DeepSORT则通过其先进的关联机制，有效处理检测器在复杂场景下（如遮挡）可能出现的挑战，确保轨迹的连续性和身份一致性。
    \item 适应铁路站台场景：在铁路站台这类高密度、高遮挡、动态背景的复杂环境中，YOLOv11的高检测能力能最大化捕获目标。同时，DeepSORT的遮挡处理和ID管理能力则能有效应对由高密度和复杂交互引起的身份切换和轨迹中断。这种协同效应使得整个系统在确保实时性的前提下，显著提升在特定复杂场景下的跟踪精度和鲁棒性。
\end{itemize}

通过这种结合，本研究旨在构建一个高效、准确且鲁棒的多目标跟踪系统，以应对铁路站台等高挑战性环境下的实际应用需求。
