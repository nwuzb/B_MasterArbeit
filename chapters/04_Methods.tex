\section{Methods}\label{section::Methods}

This study proposes a deep learning-based framework for accurate crowd counting on railway platforms by combining the YOLOv11 detector with the DeepSORT tracker and a robust counting strategy. As shown in Figure~\ref{fig:OurMOTSystemArchitecture}, the overall multi-object tracking (MOT) system integrates YOLO-based detection, EfficientNet-B0-based ReID feature extraction, and a physics-inspired Kalman filter to enable robust pedestrian tracking. The system employs a five-dimensional Extended Kalman Filter (EKF) whose state vector is $[u, v, Z, dZ, H]$, representing pixel coordinates, depth, depth velocity, and head height, respectively. Multiple gating mechanisms are adopted, including Mahalanobis distance, directional motion corridors, and adaptive appearance thresholds, to ensure reliable data association.

\subsection{YOLOv11 Model}

In 2015, Redmon et al. introduced the YOLO algorithm, a landmark in object detection \cite{76_redmon2016lookonceunifiedrealtime}. As its name suggests, YOLO detects objects and their locations in a single pass over the image by formulating detection as a regression problem, in contrast to traditional two-stage pipelines \cite{76_redmon2016lookonceunifiedrealtime}. As illustrated in Figures~\ref{fig:yolosystem-cn} and \ref{fig:yoloarchitecture-cn}, a single convolutional neural network (CNN) jointly predicts bounding boxes and class probabilities across the entire image \cite{77_Du_article}, simplifying the detection process compared to more complex traditional methods.

YOLOv11 represents a significant step forward in the YOLO family, announced at the YOLOVision 2024 (YV24) conference. It refines network design and training strategies to further improve detection accuracy and speed \cite{74_yolo11_Jocher_Ultralytics_YOLO_2023}. As noted in Related Work, using full-body cues for detection degrades substantially in crowded scenes due to heavy occlusions, whereas head cues are more discriminative and less occluded yet remain underexplored. In high-density settings, frequent and severe occlusions hinder full-body recognition, while heads, being at the upper body and less occluded with more stable shape cues, are easier to localize. Head sizes also vary less with pose, reducing both false positives and false negatives. Accordingly, we detect heads with YOLOv11 as the basis for counting.

As shown in Figure~\ref{fig:yolo11architecture-cn}, YOLOv11 introduces notable architectural and training enhancements that push the boundary of accuracy, speed, and efficiency \cite{75_khanam2024yolov11overviewkeyarchitectural}.

\subsection{Key Architectural Components of YOLOv11}
The YOLOv11 architecture comprises three fundamental components (Figure~\ref{fig:yolo11architecture-cn}). First, the backbone serves as the primary feature extractor, transforming raw images into multi-scale feature maps via CNNs. Second, the neck acts as an intermediate aggregation stage, enhancing and fusing features across scales. Third, the head produces the final predictions for localization and classification \cite{75_khanam2024yolov11overviewkeyarchitectural}.

\end{figure}

\subsubsection{Backbone Network}
The backbone extracts features at multiple scales by stacking convolutional layers and specialized blocks to produce feature maps at varying resolutions. Initial convolutional layers downsample the input, progressively reducing spatial dimensions while increasing channel depth.

SPPF and C2PSA
YOLOv11 retains the Spatial Pyramid Pooling - Fast (SPPF) block and introduces the Cross Stage Partial with Spatial Attention (C2PSA) block \cite{80_ghosh_yolo11_2024}. As shown in Figure~\ref{fig:C2PSA-cn}, C2PSA enhances spatial attention, enabling the model to focus more effectively on salient regions. By pooling spatial features, C2PSA strengthens localization of objects at different sizes and positions.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.25\linewidth]{pictures/C2PSA.png}
    \caption{C2PSA Module}
    \label{fig:C2PSA-cn}
\end{figure}

\subsubsection{Neck Network}
The neck bridges backbone and head, aggregating features from multiple scales for downstream prediction.

C3K2 block
YOLOv11 replaces the neck’s C2f blocks with C3k2 blocks, a more computationally efficient variant of the CSP (Cross Stage Partial) bottleneck. As shown in Figure~\ref{fig:C3K2-cn}, it uses two smaller convolutions instead of a single large convolution (as in YOLOv8 \cite{81_noauthor_what_2024}). The “k2” indicates smaller kernel sizes, improving speed while maintaining performance \cite{75_khanam2024yolov11overviewkeyarchitectural}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\linewidth]{pictures/C3K2.png}
    \caption{C3K2 Module\cite{83_noauthor_ultralytics_nodate}}
    \label{fig:C3K2-cn}
\end{figure}

Attention mechanism
An important addition in YOLOv11 is increased emphasis on spatial attention via C2PSA. This mechanism helps focus on key regions, yielding more accurate detection of small or partially occluded objects. This distinguishes YOLOv11 from YOLOv8, which lacks this specific attention module \cite{80_ghosh_yolo11_2024,75_khanam2024yolov11overviewkeyarchitectural}.

\subsubsection{Detection Head}
The head performs multi-scale predictions, outputting bounding-box parameters (center, width, height), class probabilities, and objectness scores. The input image is partitioned into grid cells, each responsible for objects whose centers fall within it.

C3k2 blocks
YOLOv11 employs multiple C3k2 blocks within the head to process and refine features across different depths. Behavior varies with the parameter c3k:
    • If c3k = False, C3k2 behaves similarly to C2f with a standard bottleneck.
    • If c3k = True, the bottleneck is replaced with a C3 module for deeper, more expressive feature extraction.
Key properties of C3k2:
    • Faster processing via two smaller convolutions instead of a single large convolution.
    • Parameter efficiency as a more compact CSP bottleneck.
Additionally, the C3k module allows customizable kernel sizes for improved flexibility.

CBS blocks
After C3k2 blocks, YOLOv11’s head includes several CBS (Convolution–BatchNorm–SiLU) layers \cite{81_noauthor_what_2024}, which further refine features by extracting salient cues, stabilizing flow via batch normalization, and introducing nonlinearity through SiLU.

Final convolution and detection layers
Each detection branch ends with Conv2D layers that reduce features to the required outputs for bounding-box regression and classification. The final detection layer aggregates predictions:
    • Bounding-box coordinates for localization.
    • Objectness scores.
    • Class probabilities.

\subsection{DeepSORT}
We next introduce the DeepSORT multi-object tracker. In MOT, the goal is to detect, localize, and maintain identities of multiple targets across video frames. DeepSORT (Wojke et al., 2017), an extension of SORT (Bewley et al., 2016), combines deep appearance embeddings with motion information, substantially improving tracking under complex conditions and long occlusions, and reducing identity switches (IDSW). The pipeline (Figure~\ref{fig:DeepSORT-cn}) comprises deep appearance feature extraction, a Kalman filter, and data association.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{pictures/DeepSORTAlgorithmStructure.png}
    \caption{DeepSORT architecture\cite{212}}
    \label{fig:DeepSORT-cn}
\end{figure}

The workflow can be summarized as follows:
1) Object detection: a high-performance detector identifies targets in each frame and outputs bounding boxes with confidences \cite{174}.
2) Motion prediction: a Kalman filter predicts current positions and motion states for existing tracks \cite{174}.
3) Feature extraction: deep appearance embeddings are computed for detections via a ReID model \cite{179}.
4) Data association: detections are matched to predicted tracks using a cost that combines motion (Mahalanobis distance) and appearance (cosine distance), solved with the Hungarian algorithm; a cascaded strategy further improves matching \cite{104}.
5) Track update and management: matched tracks are updated; unmatched detections initialize new tracks; long-unmatched tracks are terminated.

\subsection{DeepSORT Core Modules}

\subsubsection{Object Detector}
Tracking performance depends critically on the detector’s accuracy and speed. Typical detectors include:
• YOLO family: widely adopted for its real-time performance and accuracy (e.g., YOLOv5/YOLOv7), and in our case YOLOv11.
• Faster R-CNN: representative two-stage detector used in early variants.
• SSD: one-stage detector also used in DeepSORT systems.
• CenterNet: an anchor-free detector that can jointly output boxes and identity embeddings.
Detector improvements (e.g., lightweight backbones, dilated convolutions, SPP) are often tailored to the application.

\subsubsection{Motion Model and Kalman Filter}
Kalman filtering estimates target motion states via iterative prediction and update. The classic DeepSORT state vector is an 8-dimensional vector $\mathbf{x} = [u, v, r, h, u', v', r', h']^T$ with $(u,v)$ the center, $r$ the aspect ratio, $h$ the height, and primes denoting velocities. Prediction and update follow standard linear dynamical systems formulas:
    • $\mathbf{X}_k = \mathbf{A}\mathbf{X}_{k-1} + \mathbf{B}\mathbf{u}_k$
    • $\mathbf{P}_k = \mathbf{A}\mathbf{P}_{k-1}\mathbf{A}^T + \mathbf{Q}$
and
    • $\mathbf{G}_k = \mathbf{P}_k\mathbf{H}^T (\mathbf{H}\mathbf{P}_k\mathbf{H}^T + \mathbf{R})^{-1}$
    • $\mathbf{X}_k \leftarrow \mathbf{X}_k + \mathbf{G}_k (\mathbf{Z}_k - \mathbf{H}\mathbf{X}_k)$
    • $\mathbf{P}_k \leftarrow (\mathbf{I} - \mathbf{G}_k\mathbf{H})\mathbf{P}_k$.
While effective, a constant-velocity model can be inaccurate under strong acceleration or camera motion; extensions such as UKF and adaptive noise can better handle nonlinearities.

Physics-inspired perspective model for platform scenarios
For trains decelerating into stations, we consider a perspective projection with camera mounted at the train head, optical axis aligned with the track tangent. Let platform pedestrians be at lateral distance $D$ and head height $H$. The image-plane projection obeys
\begin{equation}
u(t)=c_u+f\frac{D}{x(t)},\quad
v(t)=c_v+f\frac{H}{x(t)},
\end{equation}
where $x(t)=x_0+v_0 t + \tfrac{1}{2} a t^{2}$ with deceleration $a<0$. The head bounding-box area scales as $A(t) \propto x^{-2}(t)$, exhibiting rapid magnification until the train passes. We construct and evaluate extended state models (adding acceleration) as well as a 5D perspective state vector grounded in this geometry; experimental settings and results are detailed in Section 5.

\subsubsection{Appearance Feature Extraction (Re-ID)}
Appearance descriptors are crucial for long-occlusion recovery and ID consistency. The original DeepSORT uses a compact residual CNN that outputs a 128-D descriptor with L2 normalization \cite{116}. Typical components include convolution and pooling layers, multiple residual blocks, and a final FC + L2 layer. The descriptors lie on the unit hypersphere for cosine similarity.

Training commonly uses large-scale video person Re-ID datasets such as MARS \cite{214} or Market-1501 \cite{215} with identity labels and bounding boxes to ensure robustness to illumination, pose, and viewpoint changes.

To accommodate diverse detection-box sizes in practice, we adopt an intelligent scaling and padding strategy:
    (1) Aspect-ratio preserving scaling to avoid distortion;
    (2) Center placement on a 128×128 black canvas for uniform input size;
    (3) Data augmentation with horizontal flips, random rotations (±15°), color jitter, and random erasing to enhance generalization.
This preprocessing aligns training and inference distributions and mitigates domain shift.

ReID loss and training
We use the triplet loss:
$$L_{triplet} = \max(0, d(a,p) - d(a,n) + \alpha)$$
with $\alpha=0.5$. Training uses AdamW (lr=2×10⁻⁴, weight decay=1×10⁻⁴), OneCycleLR scheduling, mixed precision, and batch size 32.

\subsubsection{Data Association}
Data association matches detections to tracks by combining motion and appearance cues. The similarity measures include:
• Mahalanobis distance for motion compatibility: $D_M(i, j) = (d_j - y_i)^T S_i^{-1} (d_j - y_i)$, where $d_j$ is the detection, $y_i$ the prediction, and $S_i$ the covariance \cite{105}.
• Cosine distance for appearance: $D_C(i, j) = \min \{ 1 - \mathbf{r}_j^T \mathbf{r}_k^{(i)} \mid \mathbf{r}_k^{(i)} \in R_i \}$, where $R_i$ stores up to 100 recent descriptors per track \cite{105}.
• Combined cost: $c_{i,j} = \lambda D_M(i,j) + (1-\lambda) D_C(i,j)$ \cite{105}.
Matching strategy:
• Cascaded matching prioritizes recently seen, longer-lived tracks to reduce ID switches under long occlusions \cite{134}.
• IoU matching as a fallback for remaining unmatched pairs.
• Hungarian algorithm solves the final assignment on the combined cost matrix \cite{103}.

\subsubsection{Track Management}
• Initialization: new detections start as “unconfirmed.” After three consecutive matches, a track becomes confirmed.
• Termination: tracks unmatched for a prolonged period (e.g., beyond max\_age) are removed.
• ID retention and re-identification: combined motion and appearance cues enable re-identification after temporary disappearance; prolonged absence may result in a new ID.

\subsection{Adaptivity Across Scenarios}
Parameters of Kalman filtering (state model, Q, R), gating thresholds, cost weighting, cascade/IoU matching, track lifecycle (n\_init, max\_age), and ReID strength should be tuned to scene characteristics (e.g., irregular motion, noisy detections, frequent occlusion, similar appearances) to maintain robustness.

\subsection{Counting Method}
Given YOLOv11 detections and DeepSORT trajectories, we design a reliable counting algorithm that avoids double-counting. Pure detection summation over frames would overcount the same target repeatedly; counting must therefore operate on unique track IDs.

\subsubsection{Traditional line-crossing and limitations}
The mainstream approach is line/zone crossing \cite{22_hsu_passenger_2020, 204, 68_zhao_detection_2022}, which triggers a count when a trajectory crosses a virtual line. In crowded scenes, brief occlusions near the line can cause severe undercounting (e.g., three people cross abreast but the middle person is fully occluded). As shown in our ablations (Section 5), a zero-width line (bandwidth 0) can yield MAPE as high as 93.43%.

\subsubsection{Virtual counting band (ours)}
We propose a Virtual Counting Band with nonzero width near the left/right image borders (Figure~\ref{fig:VirtualCountingZone}), defined by start/end boundaries as proportions of image width. A target is counted only if it is continuously observed within the band for a preset number of frames. This design:
\begin{itemize}
    \item \textbf{Improves robustness}: a buffer region tolerates brief occlusions and detection jitter;
    \item \textbf{Stabilizes counting}: avoids repeated or spurious counts due to oscillations around a thin line.
\end{itemize}
In practice, we set the band to 5\%–20\% of the width from the image borders (relative coordinates for resolution invariance). We maintain per-track state (consecutive in-band frames, counted flag). The target position is the box center; boxes partially outside the frame are clipped for display while preserving original coordinates for logic.

Integrity mechanisms include: (1) end-of-video compensation to include targets that nearly meet the persistence threshold; (2) deduplication by maintaining the set of counted IDs; and (3) using the maximum of left/right counts as the final result (we count one side), which avoids bias from non-platform-side flows.

\subsection{Evaluation Metrics}

\subsubsection{Detection Metrics}
We report head detection performance on a static validation set using \textbf{mAP@0.5} and \textbf{Recall}. Formally:
\textbf{mAP50}: mean AP at IoU threshold 0.5,
\begin{equation}
\text{mAP50} = \frac{1}{N}\sum_{i=1}^{N}\text{AP}_i \quad \text{at IoU threshold of 0.5}
\end{equation}
\textbf{mAP50-95}: mean AP averaged over IoU thresholds from 0.5 to 0.95 in steps of 0.05,
\begin{equation}
\text{mAP50-95} = \frac{1}{10}\sum_{t=0.5}^{0.95}\text{mAP}_t
\end{equation}
\textbf{Box Precision} and \textbf{Recall} are
\begin{equation}
\text{Precision} = \frac{TP_{\text{box}}}{TP_{\text{box}} + FP_{\text{box}}}, \quad
\text{Recall} = \frac{TP_{\text{box}}}{TP_{\text{box}} + FN_{\text{box}}}.
\end{equation}

\subsubsection{Tracking Metrics}
On MOT-TPCH we adopt MOTChallenge metrics: \textbf{IDF1}, \textbf{MOTA}, \textbf{ID Switches (IDSW)}, \textbf{MT/ML}. Following CLEAR-MOT and ID-based protocols (\texttt{py-motmetrics}):
\paragraph{CLEAR-MOT}
\begin{align}
\text{MOTA} &= 1 - \frac{\sum_t (FN_t + FP_t + IDSW_t)}{\sum_t GT_t}, \\
\text{MOTP} &= \frac{\sum_{i,t} d_{i,t}}{\sum_t TP_t},
\end{align}
where $GT_t$ is the number of ground-truth objects at time $t$, and $d_{i,t}$ is the distance between a matched hypothesis and ground truth.
\paragraph{Identity-based}
\begin{align}
\text{ID Precision (IDP)} &= \frac{IDTP}{IDTP + IDFP}, \\
\text{ID Recall (IDR)} &= \frac{IDTP}{IDTP + IDFN}, \\
\text{IDF1} &= \frac{2 \cdot IDTP}{2 \cdot IDTP + IDFP + IDFN}.
\end{align}
Additional measures: $IDSW$, Matches, $FP$, $FN$, FAF $= \tfrac{\sum_t FP_t}{\text{\#frames}}$, and standard Precision/Recall. Track quality: Mostly Tracked (MT, ≥80\%), Partially Tracked (PT, 20\%–80\%), Mostly Lost (ML, <20\%).

\subsubsection{Counting Metrics}
For $N$ test videos with predicted unique count $\hat{C}_i$ and ground truth $C_i$:
\begin{align}
\text{MAE} &= \frac{1}{N} \sum_{i=1}^{N} | \hat{C}_i - C_i |, \\
\text{RMSE} &= \sqrt{\frac{1}{N} \sum_{i=1}^{N} (\hat{C}_i - C_i)^2}, \\
\text{MAPE} &= \frac{100\%}{N} \sum_{i=1}^{N} \frac{|\hat{C}_i - C_i|}{C_i}, \\
\text{ME} &= \frac{1}{N} \sum_{i=1}^{N} (\hat{C}_i - C_i).
\end{align}
MAE reflects average absolute deviation and is robust to outliers; RMSE emphasizes larger errors; MAPE is scale-free but unstable when $C_i$ is near zero; ME (Bias) reveals systematic over/under-counting.

YOLOv11是YOLO系列发展过程中的一个重要版本继承了其高效的检测框架，YOLOv11在YOLOVision2024 (YV24) 大会上亮相，代表了实时物体检测技术的重大飞跃，它在网络结构和训练策略上进行了进一步的优化，旨在提升目标检测的精度和速度\cite{74_yolo11_Jocher_Ultralytics_YOLO_2023}。前文Related work部分的最后提到，在拥挤场景下，利用人体完整信息进行检测的效果受限严重，而头部特征作为更易识别且遮挡程度较轻的特征点，尚未被充分深入地探索和利用。因此，考虑到高密度场景下人体之间存在频繁而严重的遮挡，导致个体的整体轮廓难以完整识别，而人体头部通常位于人体上部，受到遮挡的影响较小且外形特征明显，所以更容易准确识别。并且，头部区域尺寸变化相对稳定，不受姿势变化的显著影响，有助于减少模型误检和漏检的概率，从而能够提高模型在高密度人群场景下的检测和计数精度。因此，我们使用YOLOv11来识别认人的头部作为计数依据。

4.2.1 Backbone Network
主干是 YOLO 架构的重要组成部分，负责从输入图像中提取多种尺度的特征。此过程涉及堆叠卷积层和专用块以生成条种分辦率的特征图。骨干网络通过一系列的卷积层、池化层以及激活函数对输入图像进行处理，逐步提取从低级到高级的视觉特征。

卷积层 
YOLOv11 保持了与前代产品类似的结构，利用初始卷积层对图像进行下采样。这些层构成了特征提取过程的基础，逐渐减少空间维度，同时增加通道数量。
SPPF和C2PSA 
YOLOv11 保留了以前版本的 Spatial Pyramid Pooling - Fast （SPPF）块，但在其后引入了新的 Cross Stage Partial with Spatial Attention （C2PSA）块\cite{80_ghosh_yolo11_2024}。如\ref{fig:C2PSA-cn}所示，C2PSA 块是一个值得注意的新增功能，它增强了特征图中的空间注意力机制。这种空间注意力机制使模型能够更有效地关注图像中的重要区域。通过空间池化特征， C2PSA 块使 YOLOv11 能够专注于特定的兴趣区域，从而有可能提高不同大小和位置的物体的检测精度。

C3K2块Yolo11通过用C3K2块在颈部替换颈部的C2F块来引入重大变化。C3k2块是 Cross Stage Partial （CSP） Bottleneck 的计算效率更高的实现。如\ref{fig:C3K2-cn}所示，它采用两个较小的卷积，而不是一个大卷积，如 YOLOv8\cite{81_noauthor_what_2024}中所示。C3k2 中的"k2"表示较小的内核大小，这有助于在保持性能的同时加快处理速度\cite{75_khanam2024yolov11overviewkeyarchitectural}。

注意力机制 
YOLOv11 的一个显著新增功能是它通过C2PSA 模块增加了对空间注意力的关注。这种注意力机制使模型能够专注于图像中的关键区域，从而可能实现更准确的检测，尤其是对于较小或部分遮挡的物体。加入C2PSA使YOLOv11有别于其前身YOLOv8，后者缺乏这种特定的注意力机制\cite{80_ghosh_yolo11_2024}\cite{75_khanam2024yolov11overviewkeyarchitectural}。


4.2.3 Detection Head： 负责在不同尺度的特征图上进行预测，输出目标的边界框参数（中心坐标、宽度、高度）、类别概率以及置信度得分。YOLO通常将输入图像划分为若干个网格单元（Grid Cells），每个网格单元负责预测中心落在该单元内的目标。

C3K2块
在头部部分，YOLOv11利用多个C3k2块来高效处理和细化特征图。C3k2块位于头部的多个路径中，用于处理不同深度的多尺度特征。C3k2块根据 c3k 参数的值表现出灵活性： 
    •当 c3k = False 时，C3k2 模块的行为与 C2f块类似，采用标准瓶颈结构。 
    •当 c3k = True时，瓶颈结构被C3模块取代，从而可以进行更深层、更复杂的特征提取。 
C3k2 区块的主要特征： 
•处理速度更快：与单个大卷积相比，使用两个较小的卷积可减少计算开销，从而更快地提取特征。 
•参数效率：C3k2 是 CSP 瓶颈的更紧凑版本，使得架构在可训练参数数量方面更高效。
另一个值得注意的新增功能是C3k模块，它允许自定义内核大小，从而增强了灵活性。C3k的适应性对于从图像中提取更详细的特征特别有用，有助于提高检测准确性。

CBS区块 YOLOv11 的头部在 C3k2 块之后包含几个 CBS（Convolution-BatchNorm-Silu）\cite{81_noauthor_what_2024}层。这些层通过以下方式进一步细化特征图： 
    •提取相关特征以进行准确的物体检测。 
    •通过批量标准化来稳定和规范数据流。
    •利用 Sigmoid 线性单元（SiLU）激活函数实现非线性，从而提高模型性能。
CBS 块是特征提取和检测过程中的基础组件，确保细化的特征图传递到后续层进行边界框和分类预测。 

最终的卷积层和检测层 每个检测分支以一组 Conv2D 层结束，这些层将特征減少到边界框坐标和类预测所需的输出数量。最后的检测层整合了这些预测，其中包括： 
    •用于定位图像中对象的边界框坐标。 
    •对象性分数表明对象的存在。 
    •用于确定检测到的物体的类别的类别分数。

4.3 DeepSORT
在介绍了检测器的方法之后，我们这一小节专注于介绍多目标跟踪器算法DeepSORT。
在多目标跟踪 (MOT) 领域，目标是跨视频帧检测、定位并保持多个目标的唯一身份。DeepSORT（深度简单在线实时跟踪）算法由Alex Bewley等人于2017年提出，是经典SORT（Simple Online and Realtime Tracking）算法的进一步发展和改进。如\ref{fig:DeepSORT-cn}所示，DeepSORT的核心优势在于其创新性地结合了深度学习（Deep Learning）模型提取的外观特征（Appearance Features）与运动信息（Motion Information），显著提高了目标在复杂场景下，特别是长期遮挡情况下的追踪精度和ID一致性，有效解决了SORT算法中频繁出现ID切换的问题。本节概述了该算法的核心原理、组件和公式，并应用于我们针对火车站台上的人群跟踪任务的实现中。
DeepSORT算法采用"先检测后追踪"（Tracking-by-Detection, TBD）的框架，其整体流程如\ref{fig:DeepSORT-cn},该算法由三个主要组件构成，分别为深度外观描述符提取模块、卡尔曼滤波器和数据关联模块.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{pictures/DeepSORTAlgorithmStructure.png}
    \caption{DeepSORT Architecture\cite{212}}
    \label{fig:DeepSORT-cn}
\end{figure}

其工作流程可概括为：
1. 目标检测 (Object Detection)：在每一帧图像中，使用高性能的目标检测器识别出所有目标，并生成对应的边界框及其置信度。\cite{174}
2. 运动状态预测 (Motion State Prediction)：对于现有轨迹，利用卡尔曼滤波器预测其在当前帧中的可能位置和运动状态。\cite{174}
3. 特征提取 (Feature Extraction)：对当前帧中所有检测到的目标，使用ReID模型提取其深度外观特征向量。\cite{179}
4. 数据关联 (Data Association)：通过综合考虑运动信息（马氏距离）和外观信息（余弦距离），使用匈牙利算法将当前帧的检测与预测轨迹进行最佳匹配。此外，还引入了级联匹配策略来优化匹配过程。\cite{104}
5. 轨迹更新与管理 (Track Update and Management)：根据匹配结果，更新现有轨迹的运动状态和外观特征。对于未匹配的检测，初始化为新轨迹；对于连续多帧未匹配的轨迹，则将其删除

4.4 DeepSORT核心模块详解

4.4.1. 目标检测器（Object Detector）
DeepSORT算法的性能高度依赖于前端目标检测器的准确性和实时性。检测器负责在每一帧中识别出目标，并提供其精确的边界框（bounding box）和类别置信度。这些检测结果是追踪算法的初始输入。
• 常用检测器：
    ◦ YOLO系列（You Only Look Once）：YOLO系列模型因其卓越的实时性能和检测精度而广受欢迎，常与DeepSORT结合使用。例如，YOLOv5 和YOLOv7 已被广泛用于DeepSORT的改进版本。
    ◦ Faster R-CNN：作为两阶段检测器的代表，Faster R-CNN在DeepSORT早期版本中被用于检测器。
    ◦ SSD（Single Shot MultiBox Detector）：SSD是一种单阶段检测器，也曾被应用于DeepSORT中。
    ◦ CenterNet：一种无锚框（anchor-free）检测器，能够同时输出边界框和身份嵌入信息。
• 检测器改进：针对特定应用场景，检测器常会进行轻量化或结构改进，例如在YOLOv5s模型中引入MnasNet_P结构、膨胀卷积（Dilated Convolution）和空间金字塔池化（SPP）作为骨干网络，以提高检测精度,我们这里采取上面介绍过的YOLOv11。

4.4.2. 运动模型与卡尔曼滤波器（Motion Model and Kalman Filter）
卡尔曼滤波器是DeepSORT中预测目标运动状态的核心组件。它通过迭代的预测和更新过程来估计目标的运动轨迹。
•状态向量：经典的DeepSORT使用一个8维状态向量 $\mathbf{x} = [u, v, r, h, u', v', r', h']^T$ 来描述每个目标的状态。其中：
    ◦ $(u, v)$：边界框中心的坐标。
    ◦ $r$：边界框的宽高比。
    ◦ $h$：边界框的高度。
    ◦ $(u', v', r', h')$：对应于上述四个参数在图像坐标系中的相对速度。
•预测与更新：卡尔曼滤波器根据目标在上一时刻的位置和速度信息来预测其在当前时刻的运动轨迹。这是一个迭代的、循环执行的过程。
（1）预测 (Prediction)：对于当前帧中的每个已检测目标或现有轨迹，卡尔曼滤波器会根据其前一时刻的运动信息，预测其在当前时刻的运动状态（例如，边界框的中心坐标、宽高比、高度及其对应的速度）。这一步骤旨在预估目标在当前帧中的潜在位置。预测公式如下：
        ▪ $\mathbf{X}k = \mathbf{A}\mathbf{X}{k-1} + \mathbf{B}\mathbf{u}_k$
        ▪ $\mathbf{P}k = \mathbf{A}\mathbf{P}{k-1}\mathbf{A}^T + \mathbf{Q}$ 其中，$\mathbf{X}k$ 为当前时刻的状态估计，$ \mathbf{X}{k-1}$ 为上一时刻的状态估计，$\mathbf{A}$ 为状态转移矩阵，$\mathbf{B}$ 为控制输入矩阵，$\mathbf{u}_k$ 为控制向量，$\mathbf{P}_k$ 为协方差矩阵，$\mathbf{Q}$ 为过程噪声协方差。
（2）更新 (Update)：在获得目标检测器的结果后，DeepSORT会将卡尔曼滤波器的预测结果与实际检测结果进行关联。若匹配成功，卡尔曼滤波器将更新轨迹状态，以校正预测值并获得更精确的当前时刻目标状态估计。这一更新过程有助于提高跟踪精度，尤其是在目标被部分遮挡或仅部分检测到的情况下。  
  更新公式：
        ▪ $\mathbf{G}_k = \mathbf{P}_k\mathbf{H}^T (\mathbf{H}\mathbf{P}_k\mathbf{H}^T + \mathbf{R})^{-1}$
        ▪ $\mathbf{X}_k = \mathbf{X}_k + \mathbf{G}_k (\mathbf{Z}_k - \mathbf{H}\mathbf{X}_k)$
        ▪ $\mathbf{P}_k = (\mathbf{I} - \mathbf{G}_k\mathbf{H})\mathbf{P}_k$ 其中，$\mathbf{G}_k$ 为卡尔曼增益，$\mathbf{Z}_k$ 为当前时刻的测量值，$\mathbf{H}$ 为测量矩阵，$\mathbf{R}$ 为测量噪声协方差，$\mathbf{I}$ 为单位矩阵。
• 局限性：DeepSORT中使用的线性速度模型在处理剧烈变速运动或摄像机移动的场景时可能不够准确。为解决此问题，有研究引入了无迹卡尔曼滤波器（Unscented Kalman Filter, UKF）来处理非线性误差，并引入自适应因子调整观测噪声。

针对我们的场景，列车进站减速过程中站台密集人群的人头检测与跟踪问题，设列车以恒定减速度 $a<0$ 沿轨道中心线前进，摄像机固连于车头、光轴与轨道切线重合。站台行人位于侧向距离 $D$ 处，其头部在像平面的投影服从透视模型
\begin{equation}
u(t)=c_u+f\dfrac{D}{x(t)},\quad
v(t)=c_v+f\dfrac{H}{x(t)},
\end{equation}
其中 $x(t)=x_0+v_0t+\frac{1}{2}at^{2}$，$H$ 为站台面至头顶高度。  
由此导出人头边界框面积 $A(t)\propto x^{-2}(t)$，呈指数级放大直至列车越过后消失。  
本节据此建立扩展状态向量，考虑其加速度分量，将基础8维度匀速状态向量增加为12维加速度状态向量，并构建相应过程模型。然后，我们基于上述的透视原则，新增基于物理世界的透视运动模型，将基础8维度匀速状态向量改为为5维透视状态向量，并构建相应过程模型。并对其结果进行评估，具体的实验设置和结果见第五章。

4.4.3. 外观特征提取网络（Appearance Feature Extraction Network / Re-ID Model）
外观特征是DeepSORT解决长期遮挡和ID切换问题的关键。DeepSORT通过一个深度卷积神经网络（CNN）提取每个检测目标的外观描述符。
• 网络结构：原始DeepSORT的特征提取网络是一个定制的残差CNN，输出一个128维的特征向量。它被描述为一个简单的CNN或小型CNN，并且是预训练的。一些研究中也将其称为鉴别网络（discriminative network）或重识别（Re-ID）模型。该网络结构通常包含卷积层、最大池化层和多个残差块，最后通过全连接层和L2归一化层得到最终特征\cite{116}。具体的，每个结构层的作用如下：
    ◦ 网络通常包含卷积层（convolutional layers）。用于初步提取低层次特征，部分实现中采用两个卷积层，并在降采样时可通过步长为2的卷积替代传统最大池化层
    ◦ 包含最大池化层（max pooling layer）。降低空间分辨率，减少计算量。
    ◦ 包含多个残差块（residual blocks）。例如，有描述提及它由两层卷积层和六个残差块组成。每个残差块本身可能由三个卷积层组成。在通道数逐步增加的同时缓解梯度消失问题。
    ◦ 最后，通过全连接层（fully-connected layer 或 Dense layer）和L2归一化层得到最终的特征。输出的特征向量：该网络的输出是一个128维的特征向量。这些特征向量通常经过L2归一化处理，以确保其位于单位超球面上，便于计算余弦距离。

如图：ReID-Diagram of DeepSORT\cite{211} CNN-based feature extractor.其中，红色块是简单的卷积层，黄色块是最大池层，蓝色块是残留的块，由三个卷积层组成\cite{213}。最终的绿色块表示具有批归归量的完全连接层和L2归一化。每个块的输出大小在括号中指示。

•训练：此CNN模型通常在大型行人重识别（Person Re-identification, Re-ID）数据集上进行离线训练，例如 MARS 数据集\cite{214} 或 Market-1501 数据集\cite{215}。这些数据集提供了经过标注的行人图像与视频序列，包括身份标签（ID label）与边界框位置（bounding box annotation），从而支持监督学习模型在不同光照、姿态与视角变化条件下的判别能力优化。

4.4.4.数据关联（Data Association）
数据关联是DeepSORT的关键环节，旨在将当前帧的检测结果与现有的追踪轨迹进行最佳匹配，从而保持目标身份的连续性。DeepSORT通过结合运动学信息和目标外观信息，引入了复杂的数据关联机制。其级联关联阶段（cascade association phase）多模态相似度度量，该度量包含衡量轨迹运动学兼容性的马氏距离（Mahalanobis distance）余弦距离（cosine distance）。这种方法有效地管理了相似外观或快速运动所带来的歧义\cite{141}。
• 相似性度量：
    ◦ 马氏距离（Mahalanobis Distance）：用于衡量检测边界框与卡尔曼滤波器预测轨迹之间的运动兼容性。它考虑了数据之间的协方差，能够有效滤除不太可能的关联。当仅使用马氏距离时，目标被长时间遮挡或快速移动可能导致ID切换。
        ▪ 计算公式：$D_M(i, j) = (d_j - y_i)^T S_i^{-1} (d_j - y_i)$。 其中，$d_j$ 是第 $j$ 个检测框的位置，$y_i$ 是第 $i$ 条轨迹的预测位置，$S_i^{-1}$ 是检测框与轨迹之间的协方差矩阵的逆\cite{105}。
    ◦ 余弦距离（Cosine Distance）：用于衡量检测到的目标外观特征向量与现有轨迹中存储的外观特征向量之间的相似度。为处理长期遮挡，DeepSORT为每条轨迹维护一个特征库，存储其最近成功关联的100个外观特征描述符。
        ▪ 计算公式：$D_C(i, j) = \min {1 - \mathbf{r}_j^T \mathbf{r}_k^{(i)} \mid \mathbf{r}_k^{(i)} \in R_i }$。 其中，$\mathbf{r}_j$ 是第 $j$ 个检测的特征向量，$R_i$ 是第 $i$ 条轨迹的特征库，$\mathbf{r}_k^{(i)}$ 是特征库中的特征向量\cite{105}。
    ◦ 联合距离：DeepSORT通过线性加权的方式结合马氏距离和余弦距离，形成最终的关联度量。
        ▪ 计算公式：$c_{i,j} = \lambda \cdot D_M(i,j) + (1 - \lambda) \cdot D_C(i,j)$。 其中 $\lambda$ 是权重系数\cite{105}。
• 匹配策略：
    ◦ 级联匹配（Cascade Matching）：这是DeepSORT相较于SORT的重要改进。其核心思想是优先匹配那些最近被看到、拥有更长生命周期且成功关联的轨迹。这有助于解决长期遮挡导致的目标丢失问题，并显著减少ID切换的频率\cite{134}。它通常结合了运动信息（通过马氏距离衡量卡尔曼滤波器预测与检测结果的兼容性）和外观信息（通过余弦距离衡量深度特征的相似性）来构建代价矩阵。
    ◦ IOU匹配：在级联匹配之后，对于仍未匹配的轨迹和检测框，DeepSORT会进行IOU（Intersection over Union）匹配，以处理由外观突变或部分遮挡引起的变化。
    ◦ 匈牙利算法（Hungarian Algorithm）：在计算出相似性矩阵后，DeepSORT会将其转换为代价矩阵，并结合运动信息等因素构成最终的关联成本矩阵，然后利用匈牙利算法寻找最优的检测-轨迹匹配方案，以最小化总的关联成本\cite{103}。
 
4.4.5.Track Management
DeepSORT包含一套完善的轨迹生命周期管理机制，以确保追踪的鲁棒性。
• 轨迹初始化：新的检测结果最初被视为"未确认"（Unconfirmed）轨迹。如果一个新轨迹在连续三帧内都成功匹配到检测结果，则被确认为一个新目标并开始持续追踪。
• 轨迹终止：如果一条轨迹在连续一段时间（例如，超过max_age帧，通常设置为30-70帧）内未能成功匹配到任何检测结果，则认为该目标已离开检测区域或消失，该轨迹将被删除。
• ID保持与重识别：DeepSORT通过结合运动和外观信息，在目标暂时消失（如被遮挡）后重新出现时，能够尝试重新识别并保留其原始ID。然而，如果目标长时间未被检测到并重新出现时未能成功关联，可能会被分配一个新的ID。

4.5 DeepSORT 组件在不同场景下的自适应性

在实际应用中，物体的运动模式、检测器的可靠性以及外观特征的稳定性在不同场景下可能存在显著差异。为了确保稳健的多目标跟踪性能，DeepSORT 的多个组件需要进行仔细的自适应。以下小节将对各个模块及其可调参数进行结构化概述。

(1) 卡尔曼滤波器
卡尔曼滤波器是预测被跟踪物体未来状态的核心运动模型。在 DeepSORT 中，默认假设是恒速模型，适用于以匀速或近匀速运动的物体。然而，在更复杂的运动场景中，应重新考虑以下元素：
状态空间模型（状态向量 X）：对于加速、转弯或非线性轨迹，必须扩展状态转移矩阵或状态向量本身，以更好地捕捉运动动态。
过程噪声协方差 (Q)：反映物体运动的不确定性。对于加速度较大或运动模式不规则的物体，需要增大 Q 值以避免低估运动变化。
测量噪声协方差 (R)：表示检测器的噪声水平。当使用像 YOLO 这样精度有限的检测器时，建议使用较高的 R 值，以应对不确定的测量可靠性。

(2) 门控逻辑
门控逻辑通过在数据关联之前过滤检测结果来降低计算复杂度并消除不合理的关联。
马氏距离阈值：应根据物体运动的稳定性进行调整；对于不规则轨迹，可能需要更高的阈值。
外观门控权重：在运动信息不可靠的场景下，应在门控过程中为外观特征分配更高的权重。

(3) 数据关联
数据关联通过匈牙利算法进行，该算法基于结合运动和外观信息的代价矩阵。以下参数需要调整：
代价矩阵权重：运动特征与外观特征的相对重要性应根据场景而定。例如，在高速运动场景中，由于运动预测不可靠，外观特征应具有更高的权重。
级联匹配：DeepSORT 的一项核心贡献是级联匹配，它优先考虑生命周期较长且观测值较新的轨迹，从而减少长期遮挡下的 ID 切换 \cite{134}。在高度动态的环境中，可以调整匹配优先级以平衡召回率和准确率。
并合比 (IoU) 匹配：对于级联匹配中未匹配的轨迹和检测，可以使用交并比 (IoU) 匹配作为后备方案。在外观发生变化或部分遮挡的情况下，可能需要放宽 IoU 阈值。

(4) 轨迹管理
轨迹管理控制轨迹的初始化、维护和终止：
初始化阈值 (n_init)：对于稳定的场景，较低的阈值即可满足要求。对于不稳定的运动，增加 n_init 可以防止出现虚假轨迹。
最大轨迹年龄 (max_age)：确定轨迹在不更新的情况下保留的时间。较长的值可以提高对遮挡的鲁棒性，而较短的值则可以加快稳定场景中的轨迹回收速度。
ID 保留和重新识别：通过联合利用运动和外观线索，DeepSORT 可以在暂时遮挡后重新识别目标。然而，对于长期消失的目标，需要更强大的外观模型来减少 ID 碎片化。

(5) 外观特征提取（Re-ID 模型）
Re-ID 网络提供具有判别性的外观描述符，以支持鲁棒关联。
增强特征提取：当运动线索不可靠时，提高 Re-ID 模型的判别能力（例如，采用 CNN-Transformer 混合模型）可以显著减少 ID 切换，尤其是在拥挤或视觉相似的物体场景中。

(6)总结
总而言之，运动相关参数（状态模型、Q、R）、关联逻辑（门控阈值、代价矩阵加权、级联/IoU 匹配）、轨迹管理策略（n_init、max_age）以及外观提取模块是 DeepSORT 的主要组件，应根据不同的应用场景进行调整。适当调整这些模块可以使跟踪器在各种条件下保持稳健性，包括不规则的物体运动、噪声检测、频繁的遮挡以及目标间外观相似度较高等情况。

4.6 计数方法
在获得YOLOv11与DeepSORT所输出的目标轨迹后，需要设计一套可靠的算法来统计人流量。在视频流场景中，直接统计检测框会导致对同一目标的重复计数，因此计数策略必须基于具有唯一ID的目标轨迹展开。

\paragraph{传统计数方法及其局限性}
目前，基于追踪的主流计数方法是"虚拟线/区穿越法" \cite{22_hsu_passenger_2020, 204, 68_zhao_detection_2022}。该方法在场景中预设一条虚拟的"计数线"，当目标的轨迹穿越该线时触发计数。这种方法逻辑简单，但在拥挤场景下存在明显局限性：当目标在计数线附近被短暂遮挡时，例如三个人并排通过，但中间一人被完全挡住，计数线可能只会记录到两个穿越事件，从而导致严重的漏计。如第五章的消融实验所示，单纯的计数线方法（即计数带宽度为0）的平均绝对百分比误差（MAPE）高达93.43\%，证明其在真实场景下并不可靠。

\paragraph{本研究的计数方法：虚拟计数带}
为解决上述问题，本研究设计了一种基于"虚拟计数带"（Virtual Counting Band）的计数方法。我们不再使用单薄的线，而是在画面两侧设置一定宽度的"计数区域"。如\ref{fig:VirtualCountingZone}所示，该区域由起始边界（Start）和终止边界（End）定义，其具体数值表示区域边界距离图像边缘的距离占总宽度的比例。

该方法的核心逻辑是：一个目标只有在计数带内连续出现预设的帧数（持续性检测）才被确认为有效计数。这种设计带来了两大优势：
\begin{itemize}
    \item \textbf{鲁棒性更强：} 给予了目标一个缓冲区域。即使在区域内发生短暂遮挡或检测抖动，只要目标能在后续帧中被重新稳定跟踪，就不会被遗漏。
    \item \textbf{计数更稳定：} 避免了因目标在单条线上来回徘徊而导致的重复计数或误计数问题。
\end{itemize}
通过这种方式，虚拟计数带能有效减少因遮挡导致的漏计，显著提高计数的稳定性与准确性。

\paragraph{具体实现}
考虑到监控场景中相机与人群的相对运动，本研究采用双边界计数带设计。如\ref{fig:VirtualCountingZone}所示，在视频画面的左右两侧各设置一个计数区域。根据第五章的消融实验结果，我们确定了最优参数：将计数带设置在距离画面边界5\%至20\%宽度的区域内。这一配置既能保证跟踪的稳定性（避免图像边缘的畸变和ID切换问题），又能最大化计数精度。同时，计数带的位置通过相对坐标定义，以确保方法对不同分辨率视频的适应性。

持续帧计数策略：为了提高计数的鲁棒性，避免因跟踪抖动导致的误计数，本研究采用持续帧计数策略，即持续性检测目标，要求目标需要在计数带内连续出现预设的帧数（默认为2帧）才被确认为有效计数。
因此我们对目标进行了状态管理，即为每个跟踪目标维护计数状态：统计其连续帧数和是否已计数的状态

中心点定位与边界处理：中心点计算：使用跟踪框的几何中心作为目标位置。边界框修正：对于部分超出画面边界的检测框，采用裁剪策略确保显示的完整性，同时保持原始坐标用于计数逻辑。

计数完整性保证：为确保计数的完整性，本研究实现了以下机制：
（1）最后帧补偿：在视频处理结束时，检查最后一帧中仍在计数带内但尚未达到持续帧阈值的目标，将其纳入最终计数，比如目标在在最后一帧不在计数带内，但是视频已停止，因此我们将其纳入最终计数。
（2）重复计数避免：通过维护已计数目标的ID集合，确保每个目标在整个视频序列中只被计数一次。
（3）总计数策略：最终人流统计采用左右两侧计数的最大值，我们考虑只计数一侧的目标。因此为了排除火车进站停靠，非停靠站台带来的影响，我们设置只统计一侧的数据作为最后的统计数值。

计数带显示：在视频中以半透明黄色区域标示计数带位置
状态指示：已计数目标以填充式绿色框显示，未计数目标以边框形式显示
计数信息：实时显示左侧、右侧及总计数结果
该虚拟区域计数法具有参数化灵活、鲁棒性强、适应性好等特点，能够有效处理复杂监控场景下的人流统计任务。

综上所述，本研究采用基于YOLOv11模型的直接检测方法进行火车站台人群计数。YOLOv11模型负责高效准确地检测图像中的每个人，然后通过设置的虚拟计数带，设置约束和补偿条件，来统计检测到的目标数量，并结合适当的后处理技术，采用NMS和置信度阈值过滤，最终实现对火车站台人群数量的估计。


4.7 评估指标

4.7.1 检测评估指标
%=======================  检测评估指标   =================
检测评估指标在静态图像验证集上报告头部检测的 \textbf{mAP@0.5} 与 \textbf{Recall}等指标，用于衡量微调对平台场景的适配收益，评估方法和公式如下。
In order to comprehensively evaluate the model's performance, the following metrics were adopted in this study:\\

\textbf{mAP50} 代表在IoU (Intersection over Union) 阈值为 0.5 时的平均精确度（Average Precision, AP）的均值。它主要用于评估模型在相对宽松的定位要求下的性能。
\begin{equation}
\text{mAP50} = \frac{1}{N}\sum_{i=1}^{N}\text{AP}_i \quad \text{at IoU threshold of 0.5}
\end{equation}
其中，$N$ 是类别总数，$\text{AP}_i$ 是在IoU阈值为0.5时，第$i$个类别的平均精确度。


\textbf{mAP50-95} 是在 IoU 阈值从 0.5 到 0.95、步长为 0.05 的一系列阈值下的平均精确度（mAP）的均值。该指标全面评估了模型在不同定位精度要求下的性能。
\begin{equation}
\text{mAP50-95} = \frac{1}{10}\sum_{t=0.5}^{0.95}\text{mAP}_t
\end{equation}
其中，$\text{mAP}_t$ 是在特定IoU阈值$t$下的平均精确度均值。


\textbf{Box Precision} 用于衡量模型在边界框预测方面的精确度。它计算的是正确预测的边界框（True Positives, TP）在所有预测的边界框（TP + False Positives, FP）中所占的比例。
\begin{equation}
\text{Box (Precision)} = \frac{TP_{\text{box}}}{TP_{\text{box}} + FP_{\text{box}}}
\end{equation}


\textbf{Recall} 衡量模型识别所有真实边界框（ground truth boxes）的能力。它计算的是正确预测的边界框（TP）在所有真实边界框（TP + False Negatives, FN）中所占的比例。
\begin{equation}
\text{Recall} = \frac{TP_{\text{box}}}{TP_{\text{box}} + FN_{\text{box}}}
\end{equation}

\paragraph{Summary}
In summary, the detection evaluation metrics provide a comprehensive assessment of the model's performance in accurately detecting and counting people in static images. These metrics help us understand how well the model can generalize to unseen scenarios and how it performs in different density levels of the platform scene.

4.7.2 跟踪评估指标
%=======================  跟踪评估指标   =================
\paragraph{跟踪评估指标} 在 MOT-TPCH 上采用 MOTChallenge 常用指标：\textbf{IDF1}、\textbf{MOTA}、\textbf{ID Switches (IDs)}、\textbf{MT/ML} 等。
For the quantitative evaluation of multi-object tracking (MOT) performance, we employ the widely adopted metrics implemented in the \texttt{py-motmetrics} library\footnote{\url{https://github.com/cheind/py-motmetrics}}, which is consistent with the CLEAR-MOT and ID-based evaluation protocols. Let $TP$ denote the number of true positives, $FP$ the false positives, $FN$ the false negatives (misses), $IDSW$ the number of identity switches, and $d_i$ the distance (e.g., bounding box overlap or object center distance) between matched ground truth and prediction. The metrics are defined as follows:

\paragraph{CLEAR-MOT metrics}
\begin{align}
\text{MOTA} &= 1 - \frac{\sum_t (FN_t + FP_t + IDSW_t)}{\sum_t GT_t}, \\
\text{MOTP} &= \frac{\sum_{i,t} d_{i,t}}{\sum_t TP_t},
\end{align}
where $GT_t$ is the number of ground-truth objects at time $t$, and $d_{i,t}$ denotes the distance between a matched hypothesis and ground truth.

\paragraph{Identity-based metrics}
\begin{align}
\text{ID Precision (IDP)} &= \frac{IDTP}{IDTP + IDFP}, \\
\text{ID Recall (IDR)} &= \frac{IDTP}{IDTP + IDFN}, \\
\text{IDF1} &= \frac{2 \cdot IDTP}{2 \cdot IDTP + IDFP + IDFN},
\end{align}
where $IDTP$, $IDFP$, and $IDFN$ represent identity-based true positives, false positives, and false negatives, respectively.

\paragraph{Additional measures}
\begin{itemize}
    \item \textbf{ID Switches ($IDSW$)}: the total number of times a tracked identity changes its assigned label.
    \item \textbf{Matches}: the number of correct associations between predictions and ground truth.
    \item \textbf{False Positives ($FP$)}: the number of detections not corresponding to any ground truth object.
    \item \textbf{Misses ($FN$)}: the number of ground-truth objects not detected.
    \item \textbf{False Alarms per Frame (FAF)}: average number of false positives per frame,
    \[
    \text{FAF} = \frac{\sum_t FP_t}{\text{Number of frames}}.
    \]
    \item \textbf{Precision} and \textbf{Recall}: standard definitions,
    \[
    \text{Precision} = \frac{TP}{TP+FP}, \quad \text{Recall} = \frac{TP}{TP+FN}.
    \]
    \item \textbf{Track quality measures}: a trajectory is considered
    \begin{itemize}
        \item \textbf{Mostly Tracked (MT)} if it is tracked for at least 80\% of its lifespan,
        \item \textbf{Partially Tracked (PT)} if it is tracked between 20\% and 80\%,
        \item \textbf{Mostly Lost (ML)} if it is tracked for less than 20\%.
    \end{itemize}
\end{itemize}

\paragraph{Summary}
In summary, MOTA and MOTP measure the overall tracking accuracy and precision, IDF1 (with IDP and IDR) evaluates identity preservation, and the additional measures (e.g., ID switches, MT/PT/ML) provide further insights into trajectory-level performance. Together, these metrics allow for a comprehensive and standardized assessment of MOT systems.

4.7.3 计数评估指标
%=======================   计数评估指标  =================

\paragraph{Counting Evaluation Metrics}

To quantitatively evaluate the counting accuracy of the proposed system, we report several commonly used error metrics. 
Let $\hat{C}_i$ denote the predicted unique count of video $i$, and $C_i$ the corresponding ground-truth count. 
For $N$ test videos, the following metrics are computed:
% \begin{align}
% \text{MAE} &= \frac{1}{N} \sum_{i=1}^{N} \big| \hat{C}_i - C_i \big|, \\
% \text{RMSE} &= \sqrt{\frac{1}{N} \sum_{i=1}^{N} \big(\hat{C}_i - C_i \big)^2}, \\
% \text{MAPE} &= \frac{100\%}{N} \sum_{i=1}^{N} \frac{|\hat{C}_i - C_i|}{C_i}, \\
% \text{ME (Bias)} &= \frac{1}{N} \sum_{i=1}^{N} (\hat{C}_i - C_i).
% \end{align}
1. 平均绝对误差（MAE）
平均绝对误差（Mean Absolute Error, MAE）是衡量预测计数与真实计数之间平均误差幅度的核心指标。它计算所有样本的绝对误差之和的平均值。MAE 的优势在于其直观性和易于解释性，它直接反映了系统预测结果偏离真实值的平均绝对量。由于对所有误差项进行线性惩罚，MAE 对异常值不敏感，能稳定地反映系统的整体性能。
\begin{align}
\text{MAE} &= \frac{1}{N} \sum_{i=1}^{N} \big| \hat{C}_i - C_i \big|, 
\end{align}
2. 均方根误差（RMSE）
均方根误差（Root Mean Squared Error, RMSE）是另一种评估预测精确度的常用指标。与 MAE 不同，RMSE 首先计算每个样本误差的平方，然后求其平均值，最后再开方。这种平方操作使得较大的误差被赋予更高的权重。因此，RMSE 对异常值或极端错误更加敏感。当系统对大误差的容忍度较低，或者需要评估模型在极端情况下的鲁棒性时，RMSE 是一个比 MAE 更具洞察力的指标。RMSE 总是大于或等于 MAE，其值与 MAE 的差异可以揭示模型是否偶尔会产生较大的预测偏差。
\begin{align}
\text{RMSE} &= \sqrt{\frac{1}{N} \sum_{i=1}^{N} \big(\hat{C}_i - C_i \big)^2}, 
\end{align}
3. 平均绝对百分比误差（MAPE）
平均绝对百分比误差（Mean Absolute Percentage Error, MAPE）用于衡量预测误差的相对大小，而非绝对大小。它将每个样本的绝对误差除以其对应的真实值，从而得到百分比误差，最后再求所有样本的平均值。MAPE 的优点在于其无量纲性，使得不同量级的数据集之间的性能比较成为可能。该指标尤其适用于计数范围差异较大的场景，因为它能公平地评估模型在低计数和高计数情况下的表现。然而，需要注意的是，当真实计数$C_i$接近或等于零时，MAPE 将变得不稳定或无意义。
\begin{align}
\text{MAPE} &= \frac{100\%}{N} \sum_{i=1}^{N} \frac{|\hat{C}_i - C_i|}{C_i}, 
\end{align}
4. 平均误差（ME），又称偏差（Bias）
平均误差（Mean Error, ME），也常被称为偏差（Bias），用于衡量系统的系统性偏差。它计算预测值与真实值之差的平均值。如果 ME 的值为正，则表明系统倾向于高估真实计数；如果为负，则表明系统倾向于低估真实计数。与 MAE 和 RMSE 关注误差幅度不同，ME 揭示了系统是否存在持续性的过计数或欠计数问题。该指标在需要校准模型以消除系统性偏移的应用中尤为重要。
\begin{align}
\text{ME} &= \frac{1}{N} \sum_{i=1}^{N} (\hat{C}_i - C_i), 
\end{align}
